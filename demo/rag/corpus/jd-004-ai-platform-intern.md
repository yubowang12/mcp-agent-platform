## 岗位职责

1. 参与模型服务网关开发：鉴权、限流、超时、重试与降级；
2. 维护工具注册中心，统一管理各业务方的 MCP Server 与工具描述；
3. 建设调用链监控：记录每次模型调用的耗时、token 与失败原因；
4. 编写接入文档与示例，降低业务方接入成本。

## 任职要求

1. 熟悉 Java 或 Go，理解 HTTP、连接池与超时传播；
2. 了解服务治理基本概念：熔断、限流、重试与幂等；
3. 熟悉至少一种监控体系（Prometheus / OpenTelemetry）；
4. 有较强的文档与沟通能力。

## 加分项

- 做过网关或中间件；
- 了解 SSE / Streamable HTTP 等流式传输；
- 有容器化与 CI/CD 经验。
