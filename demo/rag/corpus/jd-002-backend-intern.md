## 岗位职责

1. 参与订单中心的服务开发，负责接口设计、领域建模与单元测试；
2. 维护存量服务稳定性：慢查询治理、线程池参数调优、日志与监控补齐；
3. 参与一次服务拆分：把单体中的结算模块拆成独立服务，接口保持向后兼容；
4. 与测试、前端联调，按周交付可验证的小版本。

## 任职要求

1. 熟悉 Java 17 语法与常用集合，理解 HashMap、ArrayList 的扩容与复杂度；
2. 理解线程池、锁与 CAS，能说清 synchronized 与 ReentrantLock 的差异；
3. 熟悉 MySQL 索引与事务隔离级别，能看懂执行计划；
4. 熟悉 Spring Boot、MyBatis，了解 RESTful 设计。

## 加分项

- 读过 Spring 源码，理解 Bean 生命周期与自动装配；
- 有压测经验（JMeter / wrk），能定位 CPU 与 GC 问题；
- 了解 Redis 缓存穿透、击穿、雪崩的常用解法。

## 实习安排

导师制，两周一次 code review；表现优秀可转正。
