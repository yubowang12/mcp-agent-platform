## 岗位职责

1. 参与企业知识库问答产品开发：文档解析、分块、向量化、检索与引用；
2. 优化 RAG 链路：分块策略、混合检索（向量 + BM25）、RRF 融合与引用可追溯；
3. 编写提示词与评测集，跟踪幻觉率、召回率与回答可用性；
4. 与算法同学配合，把新模型能力接入现有服务。

## 任职要求

1. 熟悉 Python，了解 asyncio 与常见 Web 框架；
2. 理解 embedding、余弦相似度与向量数据库的基本原理；
3. 有 prompt 设计与调优经验，能写清"模型该做什么、不该做什么"；
4. 具备基本工程素养：日志、异常处理、可复现的实验记录。

## 加分项

- 做过文档分块与长文本处理；
- 了解 RAG 评测方法（命中率、MRR、引用准确率）；
- 熟悉 MCP 或 LangChain 等工具调用框架。
