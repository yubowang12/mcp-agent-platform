## 岗位职责

1. 参与 Agent 编排框架的设计与实现，包括任务规划、工具调用与结果聚合；
2. 负责 MCP（Model Context Protocol）工具服务的接入与调试，维护工具目录与描述规范；
3. 参与记忆系统的数据建模：短期会话窗口、长期偏好抽取与向量召回；
4. 编写单元测试与回归用例，配合评测同学定位失败样本。

## 任职要求

1. 熟悉 Java 或 Python 至少一门，理解 JVM 基础、常用集合与并发；
2. 了解大模型应用开发，理解 function calling、ReAct 与提示词工程；
3. 有 Spring Boot 或 FastAPI 项目经验，能独立完成接口设计与联调；
4. 每周到岗 4 天以上，实习期不少于 3 个月。

## 加分项

- 做过 RAG 或向量检索（embedding、余弦相似度、rerank）；
- 了解 MCP、A2A 等 Agent 互联协议；
- 有可展示的 GitHub 项目或技术博客。

## 面试流程

简历筛选 → 一面（项目 + 八股）→ 二面（系统设计：设计一个带工具调用的 Agent）→ HR 面。
