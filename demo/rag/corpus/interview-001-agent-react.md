## 问：什么是 ReAct？

答：Reasoning + Acting。模型先思考当前状态，再决定调用哪个工具，拿到结果后继续思考，直到信息足够或达到步数上限。关键在于把"思考"和"行动"交替进行，而不是一次性规划完所有步骤。

## 问：工具调用失败怎么处理？

答：分三层。工具侧把超时、异常、MCP isError 都转成结构化失败；编排侧单步失败不终止任务，把错误文本回填给模型让它换工具；任务侧任一步骤失败但仍有答案时标记 DEGRADED，并在 trace 里记录失败步骤与原因码。

## 问：为什么要限制最大步数？

答：防止模型陷入"调工具—失败—再调"的死循环，同时控制成本与延迟。达到上限后基于已有信息作答，并标记 MAX_STEPS，评测时与正常完成区分开。

## 问：Memory 在 Agent 里解决什么问题？

答：短期记忆解决同一会话的指代与上下文；长期记忆解决跨会话的偏好、决定与未完成事项。难点不在存，而在"该不该存、存了能不能解释、删除是否彻底"。
